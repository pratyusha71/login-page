# 🔐 Login Page

### A Simple and Elegant Login Page Using HTML & CSS

Welcome to my Login Page project! 

This project is a simple and user-friendly login interface
developed using HTML and CSS.

## 🌟 Features

- Clean and minimal user interface.
- Modern login form design.
- Username and password input fields.
- Responsive layout.
- Styled buttons and input fields.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📸 Project Preview

The project includes a beautifully designed login interface
with a simple and clean layout.

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in your web browser.
